# Installation

<Callout>
**Zero UI.** document0 is a headless documentation engine: it handles content sourcing, MDX processing, search, and navigation but ships with no UI components. You bring your own design system and have complete control over every pixel.
</Callout>

## Requirements

- Node.js 18 or later
- React 18 or later (React 19 recommended)

## Install the packages

<CodeTabs labels={["npm", "pnpm", "yarn", "bun"]}>

```bash
npm install @document0/core @document0/mdx
```

```bash
pnpm add @document0/core @document0/mdx
```

```bash
yarn add @document0/core @document0/mdx
```

```bash
bun add @document0/core @document0/mdx
```

</CodeTabs>

## Peer dependencies

You'll also need these peer dependencies depending on your setup:

<CodeTabs labels={["npm", "pnpm", "yarn", "bun"]}>

```bash
npm install shiki @mdx-js/mdx react react-dom
```

```bash
pnpm add shiki @mdx-js/mdx react react-dom
```

```bash
yarn add shiki @mdx-js/mdx react react-dom
```

```bash
bun add shiki @mdx-js/mdx react react-dom
```

</CodeTabs>

| Package | Purpose |
|---|---|
| `shiki` | Syntax highlighting for code blocks |
| `@mdx-js/mdx` | Compiling MDX at runtime |
| `react` / `react-dom` | Rendering compiled MDX |

## CLI (optional)

Install the CLI to add plugins and components from the registry:

<CodeTabs labels={["npm", "pnpm", "yarn", "bun"]}>

```bash
npm install -D @document0/cli
```

```bash
pnpm add -D @document0/cli
```

```bash
yarn add -D @document0/cli
```

```bash
bun add -D @document0/cli
```

</CodeTabs>

Then install components:

```bash
npx document0 add document0/sidebar document0/search-dialog
```

See the [CLI reference](/docs/cli) for all commands.

## Framework setup

document0 works with any Node.js framework. The [Quickstart](/docs/quickstart) guide walks through a complete Next.js setup.

For other frameworks, use `DocsSource` and `processMdx` directly; they have no framework dependencies.
