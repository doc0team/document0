# Introduction

Welcome to your documentation site, built with **document0**.

document0 gives you everything you need to build a great docs experience — file system source loading, page trees, navigation, MDX processing, and Shiki syntax highlighting — without making any decisions about your UI.

## What's included

- **File system source** — reads your `.md` and `.mdx` files and builds typed page objects
- **Page tree** — hierarchical navigation structure, ordered via `_meta.json`
- **Navigation utilities** — breadcrumbs, previous/next, active state helpers
- **MDX processing** — frontmatter, GFM, auto heading IDs, table of contents
- **Shiki code blocks** — zero-config syntax highlighting with full theme support

## How it works

Your content lives in `content/docs/`. Each file maps to a URL:

| File | URL |
|---|---|
| `content/docs/index.mdx` | `/docs` |
| `content/docs/installation.mdx` | `/docs/installation` |
| `content/docs/guides/index.mdx` | `/docs/guides` |

Use `_meta.json` in any directory to control page ordering and add separators.
